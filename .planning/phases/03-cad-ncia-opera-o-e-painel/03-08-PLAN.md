## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin → UI CRM | Correção de status, notas e tarefas partem do painel (dados de lead, PII) |
| IA → exibição | Sugestões do copiloto e notas da IA renderizadas no DOM |
| UI → dispatch | Único ponto em que texto sai do painel para o canal — sempre pelo gate |
