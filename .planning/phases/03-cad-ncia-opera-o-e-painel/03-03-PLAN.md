<objective>
Entregar a **borda HTTP local** do painel: uma única instância Fastify em `127.0.0.1` que valida `Host`+token, serve o SPA estático, expõe a API REST (leads, conversa, mensagens/histórico read-only, contadores, janela, modo, fila de handoff, ações rápidas, kill switch) e um canal SSE de tempo real — com todo envio convergindo para o gate.

Purpose: É a primeira superfície HTTP do projeto (ASVS L1). O Admin precisa de um lugar único para operar/auditar sem que o painel vire um segundo caminho de envio.

Output: `src/api/*` (server, auth, sse, rotas, schemas), `env` estendido (`PANEL_TOKEN`/`PANEL_PORT`), dependências instaladas e o painel fiado no `src/index.ts`.

Nota de granularidade: 3 tasks. Esta é uma das duas partes do painel (a outra é a SPA React — plano 03-04); o contrato REST/SSE é congelado aqui e consumido lá.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → API local | Superfície HTTP nova; token e `Host` são o único controle de acesso |
| API → banco LGPD | A API lê dados de leads (PII) e precisa não vazar por log nem por rede |
| lead/IA → DOM | Texto do lead e sugestões da IA são dados não confiáveis renderizados na UI |
